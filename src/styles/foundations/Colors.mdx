# Colors

Soft Light and Soft Dark, side by side. Components read these through `vars`, so overriding a token changes every component that uses it. Text needs 4.5:1, and control borders and focus rings need 3:1.

## Backgrounds

Contrast is `color.fg.default` on each background. Solid backgrounds such as `accent`, the statuses, and `inverse` pair with their own `onAccent`, `onStatus`, and `inverse` text, so a low value here isn't a failure.

<ColorTable group="bg" against="color.fg.default" />

## Text and icons

Contrast is against `color.bg.surface`. `onAccent`, `onStatus`, and `inverse` sit on their own backgrounds, so a low value here isn't a failure.

<ColorTable group="fg" against="color.bg.surface" />

## Borders

Contrast is against `color.bg.surface`. `subtle` is decorative. `surface` is transparent in Soft.

<ColorTable group="border" against="color.bg.surface" />

## Avatar pairs

`Avatar` colors its initials with one of six pairs, picked from the name. Each text color needs 4.5:1 on its own background. Only `Avatar` uses them, so the `background` and `color` props of `Box` don't offer them.
