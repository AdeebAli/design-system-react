# Primitives

`tokens` is the raw layer: the palette ramps, font stacks, type sizes, and spacing scale that themes are built from.

## How it relates to `vars`

`vars` is the semantic contract, such as `color.bg.accent` or `space.3`. It names what a value is for. Soft Light and Soft Dark map primitives onto it: Soft Light's `color.bg.accent` is `tokens.indigo[600]`, and its `color.bg.canvas` is `tokens.neutral[75]`. A theme can change that mapping without any component changing.

## The rule

Components never read primitives, and projects shouldn't either. Use `vars` (or the `--ds-*` variables) in styles. Use `tokens` only when building a theme with `defineTheme` or `defineFullTheme`.
