# Grid

A CSS grid with equal columns, and the base for bento layouts.

## Usage

Use `Grid` for cards, tiles, and bento layouts: content in equal columns that collapse on small screens. For a single row or column, use [`Inline`](?path=/docs/components-layout-inline--docs) or [`Stack`](?path=/docs/components-layout-stack--docs).

- `columns` sets the number of equal columns, and is responsive: `columns={{ base: '1', md: '3' }}`.
- Place children with the `gridColumn` and `gridRow` layout props, such as `gridColumn="span-2"`.
- `autoRows="equal"` makes every row as tall as the tallest.
- See [Patterns/Bento](?path=/story/patterns-bento--dashboard) for whole layouts.
- It works in server components.

## Do's and don'ts

<DoDont>

  <Dont
    code={`<Grid style={{ gridTemplateColumns: '2fr 1fr 1fr' }}>…</Grid>`}
  />
</DoDont>

## Accessibility

- `Grid` renders a `div` with no semantics. A grid of cards is often a list: use `as="ul"` with `li` children.
- Placement doesn't change the reading order. Keep the source order the order a person should read in.
