# Drawer

A modal panel from a side, or a bottom sheet, for a longer task.

## Usage

Use `Drawer` for a longer task the user may want to see the page beside, such as a filters form or an edit panel. Choose [`Dialog`](?path=/docs/components-overlays-dialog--docs) for a short, focused decision, such as a confirmation or a rename. On a phone, a `Drawer` with `side="bottom"` is a sheet.

- `DrawerTrigger` takes one element that renders a `button`, such as `Button`.
- `side` is `start` or `end`, which follow text direction and flip in right-to-left languages, or `bottom` for a bottom sheet.
- A bottom sheet is as tall as its content up to 85% of the screen height and then scrolls inside, fills the width on small screens and is centered from `md` up, and swipes down to close. It keeps a focused input above the on-screen keyboard.
- Name it with `DrawerTitle` (or `aria-label` on `DrawerContent`).
- `Escape` and the close button close it, and so does clicking outside unless `closeOnOutsideClick` is `false`.
- A controlled `Drawer` with no `DrawerTrigger` needs `finalFocus`, so focus has somewhere to return.
- It's a client component.

## Accessibility

- It's modal: focus is trapped, the page behind is inert, and scrolling is locked.
- `DrawerTitle` names it and `DrawerDescription` describes it.
