# FileUpload

Picks files, by browsing or dropping.

## Usage

Use `FileUpload` to let people choose files. It doesn't send them: the project uploads them and reports each file's status through `getFileStatus`.

- A real file input, visually hidden over the control, does the picking, so it works by keyboard, before hydration, and with phones' camera and file pickers.
- `value` is the source of truth, and the input's `files` always match it, so a form submits what's displayed.
- `variant="button"` is a compact button instead of a drop zone.
- **Checking `accept` and `maxSize` here is a convenience, not security: the server must check every upload.**
- `ref` and native attributes, such as `capture`, go to the input; `className`, `style`, and layout props go to the root.
- It's a client component.

## Accessibility

- The native file input is the focusable control, so screen readers announce it as a file picker with its label.
- Each file's status is shown in text, not only by color or an icon.
