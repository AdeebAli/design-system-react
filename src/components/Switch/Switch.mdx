# Switch

A switch, for a setting that applies immediately.

## Usage

Use `Switch` for a setting that takes effect at once, such as turning on notifications. For a choice submitted with a form, use [`Checkbox`](?path=/docs/components-forms-and-actions-checkbox--docs).

- It can be controlled (`checked` and `onCheckedChange`) or uncontrolled (`defaultChecked`).
- Give it a `label`, or name it with a `Field` label or `aria-label`.
- It's a client component.

## Accessibility

- It has the `switch` role, and Space toggles it.
- The knob's position shows the state, so color isn't the only signal.
