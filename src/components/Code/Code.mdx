# Code

Inline code, such as a prop name or a command in a sentence.

## Usage

Use `Code` for short code inside text. It's sized relative to the surrounding text, and never below 12px. Code blocks belong to [`Prose`](?path=/docs/components-typography-prose--docs), which styles `pre`.

- It works in server components.

## Do's and don'ts

<DoDont>
  <Do>
    Use it for names a person might type or search for.
    <Canvas of={CodeStories.InText} />
  </Do>
  <Dont code={`<Code>Remember to save your work</Code>`} />
</DoDont>

<DoDont>

## Accessibility

- It renders a `code` element. Screen readers read it as normal text, so the sentence around it must make sense.
