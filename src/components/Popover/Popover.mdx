# Popover

A small panel beside its trigger, with the page still usable.

## Usage

Use `Popover` for a small panel, such as quick filters or details, while the page stays usable. For a task that needs full attention, use [`Dialog`](?path=/docs/components-overlays-dialog--docs); for a list of actions, [`Menu`](?path=/docs/components-overlays-menu--docs); for a hint on hover, [`Tooltip`](?path=/docs/components-overlays-tooltip--docs).

- `PopoverTrigger` takes one element that renders a `button`, such as `Button`.
- Name it with `PopoverTitle` (or `aria-label` on `PopoverContent`).
- It doesn't open on hover.
- `arrow` is off by default, since the theme's shadows already separate the popup.
- A `Dialog` opened from an open popover sits underneath it, so close the popover first.
- It's a client component.

## Accessibility

- It's non-modal: the page stays usable. Focus moves into it and back to the trigger on close, and `Escape` or a click outside closes it.
