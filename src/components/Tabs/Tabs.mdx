# Tabs

Switches between panels on the same page.

## Usage

**Tabs or links?** `Tabs` switch between panels in the same page, without changing the URL. For links between pages, use [`NavBar`](?path=/docs/components-navigation-navbar--docs); a URL-driven row of tabs should be links, not `Tab`.

- Build it from `Tabs`, a `TabsList` of `Tab`s, and a `TabsPanel` for each, matched by `value`.
- Set `value` or `defaultValue`.
- Closed panels aren't rendered unless `keepMounted` is set.
- It's a client component.

## Do's and don'ts

<DoDont>
  <Do>
    Name the list, and keep tab labels short.
    <Canvas of={Stories_.Playground} />
  </Do>
  <Dont
    code={`<TabsList>
  <Tab value="a">Overview of your account settings</Tab>
</TabsList>`}
  />
</DoDont>

<DoDont>
  <Do>Use links for tabs that change the URL.</Do>
  <Dont
    code={`<Tab value="billing" onClick={() => router.push("/billing")}>Billing</Tab>`}
  />
</DoDont>

## Accessibility

- Arrow keys move focus between tabs, and `Enter` or `Space` selects one, so moving through tabs doesn't load content by accident.
- Name the list with `aria-label` or `aria-labelledby`.
- Each panel is labeled by its tab.
