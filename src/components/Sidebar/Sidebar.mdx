# Sidebar

An app's main navigation, down one side of the page.

## Usage

Use `Sidebar` for an app with many sections. For a site with a few top-level pages, use [`NavBar`](?path=/docs/components-navigation-navbar--docs).

- Group links with `SidebarGroup`, whose `label` names its list. Set `active` on the current page's link: the library doesn't read the URL.
- It stays in view at full height (`sticky`, the default) and its links scroll inside it, while `brand` and `footer` stay put.
- `collapsible` adds a button, from `md` up, that shrinks it to a rail of icons with tooltips; links then need a `startIcon`, and a `badge` becomes a dot.
- Below `md`, a bar with `brand` and a menu button replaces it, and the button opens the links in a drawer from the start edge; a link click closes it, unless it opens a new tab.
- Page layout is yours: put it in a `Flex` with `direction={{ base: 'column', md: 'row' }}`, beside a `Box as="main" flexGrow="1" minWidth="0"`. See [Patterns/App navigation](?path=/story/patterns-app-navigation--desktop).
- Pass a router link through `as`, such as `as={NextLink}`.
- It's a client component.

## Accessibility

- It renders a `nav` landmark named by `aria-label`, which its types require, so several `nav`s stay distinguishable.
- The active link gets `aria-current="page"`.
- In the rail, each link keeps its text as its name, and a tooltip shows it.
- The small-screen drawer traps focus and returns it to the menu button when it closes.
