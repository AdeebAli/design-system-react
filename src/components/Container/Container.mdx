# Container

Centers a page's content, with a maximum width and side padding.

## Usage

Use one `Container` per page region, such as the main content, to set its width. Inside it, lay out with [`Stack`](?path=/docs/components-layout-stack--docs) and [`Grid`](?path=/docs/components-layout-grid--docs).

- `size` sets the maximum width: `sm`, `md`, `lg` (the default), `xl`, `prose`, or `full`.
- The side padding is `4`, and `6` from `md`. `paddingX="0"` removes it.
- It works in server components.

## Do's and don'ts

  />
</DoDont>

## Accessibility

- `Container` renders a `div`. Use `as="main"` for the page's main content, so screen readers can jump to it.
- The maximum width keeps lines readable at large sizes; text still reflows when zoomed.
