# DataTable

A table that manages sorting, pagination, selection, and loading and empty states.

## Usage

Use `DataTable` for client-side data that people sort, page through, and select. Use [`Table`](?path=/docs/components-data-table--docs) for display and server rendering, and see [Patterns/Data](?path=/story/patterns-data--customers-table) for a full page.

- A sortable header cycles ascending, descending, unsorted; `null` sorts last.
- With `selectionMode`, the row header becomes a toggle button and a click anywhere on a row toggles it.
- Name it with `aria-label` or `aria-labelledby`; its types require one.
- It's a client component.

## Accessibility

- It renders a native table, named by `aria-label` or `aria-labelledby`.
- Sortable headers are buttons, with `aria-sort` on the header cell.
- While loading, it's marked busy, and skeleton rows hold the place.
