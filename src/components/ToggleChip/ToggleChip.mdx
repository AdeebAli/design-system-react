# ToggleChip

A selectable pill, such as a filter.

## Usage

Use `ToggleChip` for a filter or tag that's on or off. Group chips with [`ToggleChipGroup`](?path=/docs/components-forms-and-actions-togglechipgroup--docs). For a status label that isn't clickable, use [`Badge`](?path=/docs/components-display-badge--docs).

- It can be controlled (`pressed` and `onPressedChange`) or uncontrolled (`defaultPressed`).
- A pressed chip shows a check, so its state isn't shown by color alone.
- It's a client component.

## Accessibility

- It's a toggle button with `aria-pressed`, so screen readers say whether it's pressed.
- An icon in `startIcon` is decorative.
