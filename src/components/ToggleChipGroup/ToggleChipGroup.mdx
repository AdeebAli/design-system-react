# ToggleChipGroup

A wrapping row of `ToggleChip`s.

## Usage

Use `ToggleChipGroup` for a set of filters. Name it with `aria-label` or `aria-labelledby`; its types require one.

- One chip is pressed at a time unless `multiple` is set.
- Pressing the selected chip clears it. To keep one always selected, as with an "All" filter, control `value` and ignore empty changes.
- It's a client component.

</DoDont>

## Accessibility

- The group has the `group` role with its name. Tab moves into it, and arrow keys move between chips.
