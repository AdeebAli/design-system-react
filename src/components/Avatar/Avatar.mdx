# Avatar

A person or organization, with initials until the image loads, and a status.

## Usage

Use `Avatar` for a person or an organization. For any other image, use [`Image`](?path=/docs/components-image-image--docs).

- `name` is required: it's the accessible name and the source of the initials, which show until the image loads and if it fails. The image is in the server HTML.
- `colorFromName` picks one of six color pairs from the name, so the same name always gets the same color, but different names can share one.
- It's a client component.

## Accessibility

- A screen reader hears the name once, with the status when set, such as "Ada Park, online".
- Status is displayed, not announced when it changes.
