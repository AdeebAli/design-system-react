# Combobox

A single choice from a long list, found by typing.

## Usage

Use `Combobox` when the list is long enough that people would rather type, such as countries or people. For a short list, use [`Select`](?path=/docs/components-forms-and-actions-select--docs); for several choices, [`MultiSelect`](?path=/docs/components-advanced-inputs-multiselect--docs). Label it with a [`Field`](?path=/docs/components-forms-and-actions-field--docs).

- Only listed options can be chosen. Leaving the input with unmatched text restores the selected label.
- It takes the same `options` as `Select`, and `null` means nothing is selected. With React Hook Form, use `Controller` and a default of `null`.
- Results are filtered locally unless `onSearch` is set; then `loading` shows while the project fetches.
- `ref` and native attributes go to the `input`; `className`, `style`, and layout props go to its wrapper.
- It's a client component.

## Do's and don'ts

    code={`<Combobox options={results} onSearch={(q) => fetch(\`/api?q=\${q}\`)} />
// A request on every keystroke`}
  />
</DoDont>

## Accessibility

- The input has the `combobox` role and controls a listbox. Arrow keys move through results, Enter selects, and Escape closes the list.
- The number of matches is announced as people type.
