# Field

Connects a label, hint, and error to one control.

## Usage

Wrap each form control in a `Field` to give it a visible label, an optional hint, and an error. It displays them; it doesn't manage form state or validate. See [React Hook Form](?path=/docs/guides-react-hook-form--docs) for wiring controls to a form library.

- `error` marks the field invalid, and needs text that says how to fix the problem.
- `required` sets `aria-required` and shows a `*`, without native validation bubbles. For native validation, put `required` directly on `Input` or `Textarea`.
- `disabled` and `invalid` reach the control inside, so they're set once.
- For a group of radios or checkboxes, the `Field` labels the group.
- It's a client component.

## Accessibility

- For a native control, such as `Input`, the label is a real `label`. For a button-based control or a group, such as `Select` or `RadioGroup`, the label names it, and clicking the label focuses it.
- The hint and error are linked to the control as its description, so screen readers read them when it's focused.
- `error` sets `aria-invalid` on the control.
- The project writes the label and error text.
