# Tooltip

A short, visual-only hint on hover or keyboard focus.

## Usage

Use `Tooltip` to show a control's name or a keyboard shortcut to sighted mouse and keyboard users. For anything people need, use visible text or a [`Popover`](?path=/docs/components-overlays-popover--docs).

- It doesn't appear on touch screens, so never put needed information in one.
- `delay` applies to hover only; keyboard focus opens it immediately. With `delay={0}`, a tap can flash it open for one frame.
- `TooltipProvider` is optional: inside one, a second tooltip opens without delay soon after the first closes.
- A natively `disabled` button fires no hover or focus events, so its tooltip won't open: use `aria-disabled` instead of `disabled`, or wrap it in a focusable element.
- It's a client component.

  <Input type="password" />
</Tooltip>`}
  />
</DoDont>

## Accessibility

- It's visual only: Base UI adds no ARIA, so `content` isn't announced. The trigger needs its own name.
