# Divider

A line between things, horizontal or vertical, optionally with a label.

## Usage

Use `Divider` to separate groups that spacing alone doesn't, such as two kinds of sign-in. Most layouts need only spacing: use `gap` on a [`Stack`](?path=/docs/components-layout-stack--docs).

- It has no margins of its own, so add them with layout props such as `marginY`.
- With `label`, the text sits in the middle of the line, such as "or" between two buttons.
- It works in server components.

## Do's and don'ts

## Accessibility

- By default it's an `hr`, which screen readers announce as a separator. `decorative` defaults to `false` because an extra separator is the safer mistake.
- With `label`, the text is read like any other text, and the lines aren't announced.
