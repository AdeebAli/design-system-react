# Breadcrumbs

Where a page sits, with links back up.

## Usage

Use `Breadcrumbs` on pages deep in a hierarchy, such as a settings page or a document in a folder.

- Each `BreadcrumbItem` takes `href` (and a router link through `as`), or `current` for the page itself.
- Long trails wrap.
- There's no `"use client"` and no context, so it works in a server component, with a server-defined `as` too.

## Do's and don'ts

<DoDont>
  <Do>
    Mark the last item `current`.
    <Canvas of={Stories_.Default} />
  </Do>
  <Dont
    code={`<Breadcrumbs aria-label="Breadcrumb">
  <BreadcrumbItem href="/">Home</BreadcrumbItem>
  <BreadcrumbItem href="/settings/billing">Billing</BreadcrumbItem>
</Breadcrumbs>
// The current page is a link to itself`}
  />
</DoDont>

<DoDont>
  <Do>Use it alongside the main navigation, not instead of it.</Do>
  <Dont
    code={`<Breadcrumbs aria-label="Breadcrumb">
  <BreadcrumbItem current>Home</BreadcrumbItem>
</Breadcrumbs>
// One item says nothing`}
  />
</DoDont>

## Accessibility

- It renders a `nav` landmark with an ordered list.
- The `current` item renders text with `aria-current="page"`.
- Separators come from CSS, are hidden from screen readers, and flip in right-to-left text.
