# Stack

Children from top to bottom, with a gap from the spacing scale.

## Usage

Use `Stack` for most vertical layout: a form's fields, a card's content, a page's sections. Use [`Flex`](?path=/docs/components-layout-flex--docs) to change direction, and [`Inset`](?path=/docs/components-layout-inset--docs) to add padding.

- The gap defaults to `3`. Pick a larger step between groups than inside them.
- Children stretch to its width unless `align` says otherwise.
- It works in server components.

## Accessibility

- `Stack` renders a `div` with no semantics. Use `as="ul"` for a list, or `as="section"` with a heading.
- Hiding a child with `display="none"` hides it from screen readers too.
