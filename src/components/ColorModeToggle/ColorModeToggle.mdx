# ColorModeToggle

An `IconButton` that switches between light and dark.

## Usage

Put `ColorModeToggle` in a header or settings area. It switches the mode through `useColorMode`, inside a `ThemeProvider`.

- Clicking stores the opposite of what's on screen. "system" stays the starting point until someone clicks.
- Before hydration it renders an icon-less button with a neutral name, at its final size, so nothing shifts.
- It renders nothing when the mode is forced.
- For a three-way light, dark, and system choice, build a [`Menu`](?path=/docs/components-overlays-menu--docs) with `useColorMode`. See [Themes](?path=/docs/guides-themes--docs).
- It's a client component.

## Accessibility

- Its name says what a click does, "Switch to dark mode" or "Switch to light mode", and changes with the mode.
- It's a native `button`.
