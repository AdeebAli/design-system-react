# Menu

A list of actions, with submenus and checkbox or radio items.

## Usage

Use `Menu` for a list of actions, such as a row's edit, duplicate, and delete. It isn't for navigation bars or choosing a form value: use [`NavBar`](?path=/docs/components-navigation-navbar--docs) and [`Select`](?path=/docs/components-forms-and-actions-select--docs).

- `MenuTrigger` takes one element that renders a `button`, such as `Button`.
- `MenuItem` and `MenuLinkItem` close the menu on click; checkbox and radio items stay open.
- `MenuLinkItem` takes `as` for a router link.
- Group items with `MenuGroup` and `MenuGroupLabel`, and split groups with `MenuSeparator`. Nest a menu with `MenuSubmenu`, `MenuSubmenuTrigger`, and `MenuSubmenuContent`.
- It's a client component.

## Accessibility

- Arrow keys, Home, End, type-ahead, and `Escape` work as in any menu, and focus returns to the trigger on close.
- It's non-modal, so the page keeps scrolling.
- Checkbox and radio items announce their checked state.
