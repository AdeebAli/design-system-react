# Text

Body text, with sizes, weights, and colors from the type tokens.

## Usage

Use `Text` for any text that isn't a heading. For headings, use [`Heading`](?path=/docs/components-typography-heading--docs), and for long-form content, [`Prose`](?path=/docs/components-typography-prose--docs).

- It renders a `p`. Use `as="span"` inside a sentence, and `as="label"` for a label.
- Unset props inherit, so `<Text as="span">` keeps the surrounding style.
- `truncate` keeps one line with an ellipsis, and `lineClamp` keeps several.
- `numeric` uses tabular numerals, so digits line up in columns.
- It works in server components.

## Accessibility

- [Colors](?path=/docs/foundations-colors--docs) lists each tone's contrast in both modes. Never use color as the only signal.
- Truncated text is cut off for everyone. Keep the full text available, such as on the page it links to, or don't truncate.
- Sizes are in `rem`, so text follows the browser's font size setting.
