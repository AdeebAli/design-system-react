# MultiSelect

Several choices, from a short list or, with `searchable`, a long one.

## Usage

Use `MultiSelect` for several choices, such as tags or assignees. For one choice, use [`Select`](?path=/docs/components-forms-and-actions-select--docs) or [`Combobox`](?path=/docs/components-advanced-inputs-combobox--docs). For a few on/off filters that should stay visible, use [`ToggleChipGroup`](?path=/docs/components-forms-and-actions-togglechipgroup--docs).

- Values are `string[]`, and `[]` is the empty value.
- By default it's a button like `Select`'s, showing the first label and a count, such as "Design +2". The popup stays open while choosing.
- With `searchable`, it's chips and a search input instead, for a long list.
- `ref`, `className`, and layout props go to the trigger by default, and to the input and chip wrapper with `searchable`.
- It's a client component.

## Accessibility

- Every selected label is in the trigger's description, so truncation such as "Design +2" hides nothing from screen readers.
- Arrow keys move through options, and Enter or Space toggles one. In `searchable` mode, Backspace in an empty input removes the last chip.
