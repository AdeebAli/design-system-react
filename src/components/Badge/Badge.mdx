# Badge

A small, non-interactive status label.

## Usage

Use `Badge` for a status or count next to something, such as "Draft" or "3 new". For selectable pills, use [`ToggleChip`](?path=/docs/components-forms-and-actions-togglechip--docs). For a message, use [`Alert`](?path=/docs/components-feedback-and-display-alert--docs).

- The text must carry the meaning, since color alone can't.
- It works in server components.

## Accessibility

- It's plain text in a `span`, with no role, so it's read in line with the content around it.
- An icon in `startIcon` is decorative.
