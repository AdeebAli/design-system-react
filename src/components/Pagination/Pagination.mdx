# Pagination

Page links, or buttons, for a long list split into pages.

## Usage

Use `Pagination` under a list or table split into pages. [`DataTable`](?path=/docs/components-data-datatable--docs) has its own.

- With `getHref` it renders links, which work without JavaScript, open in a new tab, and keep the page in the URL; this works from a server component. Pass a router link through `as`.
- With `onPageChange` it renders buttons and needs a client parent.
- Long ranges keep the same number of items while paging, so buttons don't shift.
- Below `sm` it shows previous, "Page 3 of 10", and next.

## Do's and don'ts

## Accessibility

- It renders a `nav` landmark with a list. The current page gets `aria-current="page"`.
- Previous and next have names, which `labels` can translate.
