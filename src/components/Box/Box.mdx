# Box

The primitive every component is built on: an element with style props that accept tokens only.

## Usage

Reach for a layout component first: [`Stack`](?path=/docs/components-layout-stack--docs), [`Inline`](?path=/docs/components-layout-inline--docs), [`Flex`](?path=/docs/components-layout-flex--docs), or [`Grid`](?path=/docs/components-layout-grid--docs). Use `Box` when none of them fits, such as a `main` element that grows to fill a row, or a styled element with no layout of its own.

- Every style prop takes a token, and most are responsive: `padding={{ base: '2', md: '4' }}`. The full list is on [All style props](?path=/docs/components-layout-box-all-style-props--docs).
- `as` renders another element or component, such as `as="main"` or a router's link.
- A style prop wins over an HTML attribute of the same name, so `width` is the style prop. Use `htmlWidth` and `htmlHeight` for an `img`'s real `width` and `height` attributes.
- `box()` returns the same classes as a string, for an element you don't render through `Box`.
- It works in server components.

## Accessibility

- `Box` adds no semantics: a `div` means nothing to a screen reader. Use `as` for the right element, such as `as="nav"`, `as="main"`, or `as="section"` with a heading.
- `display="none"` hides content from everyone, screen readers included. To hide text only visually, use [`VisuallyHidden`](?path=/docs/components-typography-visuallyhidden--docs).
