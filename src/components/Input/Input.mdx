# Input

A single-line text input.

## Usage

Use `Input` for short text, such as a name, an email, or a search. For several lines, use [`Textarea`](?path=/docs/components-forms-and-actions-textarea--docs); for a choice from a list, [`Select`](?path=/docs/components-forms-and-actions-select--docs) or [`Combobox`](?path=/docs/components-advanced-inputs-combobox--docs). Label it with a [`Field`](?path=/docs/components-forms-and-actions-field--docs).

- It keeps the native `value` and `onChange`, so it works with React Hook Form's `register`.
- `ref` and native attributes go to the `input`. `className`, `style`, and layout props go to its wrapper, which also draws the focus ring around any icons.
- Text is 16px on touch screens, so iOS doesn't zoom.
- It's a client component.

## Accessibility

- It renders a native `input`, so it works with every assistive technology and with autofill.
- In a `Field`, it gets the label, hint, error, and `aria-invalid`.
- Icons are decorative.
